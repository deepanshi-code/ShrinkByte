ShrinkByte High-Level System Architecture

The architecture executes byte-level frequency analysis, binary min-heap construction, optimal prefix code tree generation, and metadata bit packing.

1. Input File & FileManager: Reads raw byte streams from .txt, .csv, .c, .cpp up to 1 GB.
2. Frequency Table: Compiles occurrence counts of each 8-bit character (0 to 255).
3. Minimum Heap: Efficient $O(N \log N)$ priority queue that repeatedly extracts the two smallest nodes.
4. Huffman Tree: Merges nodes into a binary tree where frequent characters occupy shorter tree depths.
5. HuffmanEncoder & MetadataManager: Translates bytes to bit-strings, packs 8 bits into bytes, and prepends tree serialization & padding length.
6. HuffmanDecoder & Decompressor: Reads the compressed bitstream, traverses the tree to decode original symbols, and recreates the source file with 100% losslessness.
